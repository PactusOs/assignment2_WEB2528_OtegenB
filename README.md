# Assignment #2 — Advanced CSS

This project implements the Advanced CSS assignment using Flexbox and CSS Grid.

## Pages

- `index.html` — project home page and navigation
- `task1-flexbox.html` — Task 1: Flexbox card row
- `task2-grid.html` — Task 2: Grid areas layout
- `task3-gallery.html` — Task 3: nine-image CSS Grid gallery
- `task4-portfolio.html` — Task 4: portfolio combining Flexbox and Grid
- `styles.css` — one shared stylesheet for all pages

## How to run

Open `index.html` in a browser, or publish the folder with GitHub Pages or Netlify.

Before submission, replace `Your Name` and `Your Group` on the portfolio page with the student's details.
